    ✅ الإجابة: أ) i = dq/dt
  2. 2. وحدة قياس التيار الكهربائي في النظام الدولي هي:
    ✅ الإجابة: ب)
  3. 3. إذا مرت شحنة مقدارها 0.123C في زمن قدره 879 ثانية، فما قيمة التيار؟
    ✅ الإجابة: أ) i = q/t = 0.123/879 = 0.14 × 10⁻³ A
  4. 4. كثافة التيار الكهربائي (J) تُعرف بأنها:
    ✅ الإجابة: ب) J = i/A
  5. 5. سرعة الانجراف (v_d) للإلكترونات في الموصلات النموذجية تكون تقريباً:
    ✅ الإجابة: ب)

🔹 الجزء الثالث: قانون أوم والتطبيقات

  1. 11. قانون أوم يُعبَّر عنه بالمعادلة:
    ✅ الإجابة: ب)
  2. 12. مصباح مقاومته 240Ω متصل بمصدر جهد 120V. ما التيار المار فيه؟
    ✅ الإجابة: أ) I = V/R = 120/240 = 0.5 A
  3. 13. سخان كهربائي قدرته 1500W يعمل على جهد 220V. ما التيار الذي يسحبه؟
    ✅ الإجابة: ب) I = P/V = 1500/220 ≈ 6.82 A
  4. 14. القدرة الكهربائية (P) تُحسب بجميع العلاقات التالية ما عدا:
    ✅ الإجابة: د) العلاقة الخاطئة
